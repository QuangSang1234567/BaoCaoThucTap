## Learning about AWS IAM and access management

## Weekly objectives

Understand how IAM manages identities and controls access to AWS resources.

## Tasks for this week (4 sessions)

| Session | Learning activity | Study source |
| --- | --- | --- |
| Session 1 | Study IAM, identity, authentication and authorization. | [First Cloud AI Journey](https://cloudjourney.awsfcaj.com/) |
| Session 2 | Study IAM users, groups and organizing user identities. | [First Cloud AI Journey](https://cloudjourney.awsfcaj.com/) |
| Session 3 | Study IAM policies and how they allow or deny actions. | [First Cloud AI Journey](https://cloudjourney.awsfcaj.com/) |

## Learning outcomes

Distinguished users, groups, policies and roles, and understood access management using least privilege.
