## Learning about AWS Cloud9, AWS CLI and IAM roles

## Weekly objectives

Become familiar with AWS development and command-line tools and understand application permissions through roles.

## Tasks for this week (3 sessions)

| Session | Learning activity | Study source |
| --- | --- | --- |
| Session 1 | Study Cloud9 and browser-based development environments. | [First Cloud AI Journey](https://cloudjourney.awsfcaj.com/) |
| Session 2 | Study the AWS CLI, initial setup and working with AWS services through the command line. | [First Cloud AI Journey](https://cloudjourney.awsfcaj.com/) |
| Session 3 | Study IAM roles and application access to AWS services; compare roles with IAM users. | [First Cloud AI Journey](https://cloudjourney.awsfcaj.com/) |

## Learning outcomes

Learned the purposes of Cloud9, AWS CLI and IAM roles and gained a basic understanding of tools and applications working with AWS services.
